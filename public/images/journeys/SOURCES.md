# Itinerary photographs

Supplied by Atlas from the `safari_images` library on 25 September 2026. Every
itinerary carries its own photograph — no image is used by two journeys. They
illustrate the style of the journey; they do not identify the named camps,
routes, or guides.

All files are cropped to 3:2 and saved as progressive JPEG, so the same file
reads correctly in the full-bleed hero, the 5:6 related-journey card, and the
list thumbnail.
